# shadowscout — расширение для автозаполнения купона

Показывает активные рекомендации из shadowscout и подставляет сумму ставки
в поле купона у букмекера. **Никогда** не нажимает кнопку подтверждения —
ставку размещаешь ты сам(а), расширение только избавляет от ручного ввода
суммы.

## Установка

1. `chrome://extensions` → включить «Режим разработчика» → «Загрузить
   распакованное расширение» → выбрать эту папку (`extension/`).
2. Открой попап расширения, укажи публичный адрес твоего API (`shadowscout.api`) и
   `EXTENSION_API_TOKEN` из `.env` (сгенерировать:
   `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`).

## Почему заполнение сумм пока не работает ни на одном сайте

`content.js` содержит по одной записи на 1xbet, fonbet, bet365 и winline,
и каждая сейчас `null` — я намеренно не угадываю CSS-селекторы для формы
с реальными деньгами: угаданный селектор может либо ничего не найти
(безопасно, но бесполезно), либо случайно попасть не в то поле — это
хуже, чем открыто ничего не делать.

Сайты с защитой от ботов (Fonbet показывает капчу автоматическому браузеру)
можно разобрать только в твоём обычном браузере, так что разметка нужна от тебя.

### Что мне нужно от тебя для каждого сайта

1. Залогинься на сайте, открой любой матч, добавь исход в купон.
2. Открой DevTools (F12) → вкладка Elements.
3. Кликни правой кнопкой по **полю ввода суммы ставки** → Inspect.
4. Правой кнопкой по подсвеченному элементу в дереве → Copy → Copy outerHTML.
5. Пришли этот HTML (плюс, если поле находится внутри необычного контейнера
   — пары родительских тегов вокруг).

Как только пришлёшь разметку хотя бы для одного сайта, впишу настоящий
`stakeInput`-селектор в `SELECTORS_BY_HOST` в `content.js`, и заполнение
для этого сайта заработает по-настоящему — без плейсхолдеров.
